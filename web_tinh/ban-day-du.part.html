Cách chạy bản đầy đủ

  1. Mở terminal ở thư mục đồ án.
  2. python -m venv .venv (chỉ lần đầu), rồi source .venv/bin/activate (Windows: .venv\Scripts\activate).
  3. pip install -r requirements.txt
  4. python app.py, rồi mở http://127.0.0.1:5000
