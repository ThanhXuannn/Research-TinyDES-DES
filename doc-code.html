Đọc trang này thế nào?

Slide nóiCâu chữ trong tài liệu Chương 2, kèm số trang.
Hiểu nôm naCùng ý đó, nói bằng lời thường, có ví dụ.

Các biếnMỗi biến là một cái hộp có tên. Bảng ghi hộp đựng gì khi chạy ví dụ.

Ví dụ TinyDES: bản rõ 01011100, khóa 10011010 (bài tập slide 72). Ví dụ DES: khối 0123456789ABCDEF, khóa 133457799BBCDFF1. Mọi con số do chính code tính ra lúc bạn mở trang.

3 điều cần biết trước khi đọc code Python:

1. x = 5 nghĩa là bỏ 5 vào hộp tên x, không phải “x bằng 5” như toán. Gán lại thì giá trị cũ mất.

2. def ten(a, b): là định nghĩa một cái máy tên ten, nhận 2 thứ a, b. Các dòng thụt vào bên dưới là việc máy làm. return là thứ máy trả ra.

3. Chữ sau dấu # là ghi chú cho người đọc, máy bỏ qua. Code của nhóm có ghi chú kèm ví dụ ở gần như mọi dòng.

Hoán vị, dịch vòng trái, và phép ⊕ (XOR).

Hiểu nôm na

permute: chép ô theo bảng. permute("1100", EXPAND) = "001011".

44def permute(bits, table):
45    """
46    Hoán vị / mở rộng / nén chuỗi bit theo bảng (chỉ số bắt đầu từ 0 như tài liệu).
47    VD: permute("0110", EXPAND) = "101110"        (b2 b3 b1 b2 b1 b0 = 1 0 1 1 1 0)

54def left_shift(bits, n):

56    Dịch vòng trái n bit.

A3

Làm 3 chìa K1, K2, K3

slide 71 · hàm generate_keys

Slide nói

Khóa K 8 bit chia thành KL0, KR0. Vòng 1 dịch vòng trái 1 bit, vòng 2 dịch 2 bit, vòng 3 dịch 1 bit. Kᵢ = nén KLᵢKRᵢ thành k5 k1 k3 k2 k7 k0.

Hiểu nôm na

Cắt khóa làm 2 nửa. Mỗi vòng: xoay tiếp cả 2 nửa, ghép lại 8 ô, chọn 6 ô làm chìa. Làm 3 lần ra 3 chìa.

Khóa 10011010 → K1 101110, K2 110011, K3 001001

core/tinydes_core.pydòng 95–118
95def generate_keys(key_8bit, log=None):
96    """
97    Sinh K1, K2, K3 (mỗi khóa 6 bit) từ khóa 8 bit:
98      chia KL0 | KR0 (4 bit | 4 bit) -> vòng i: dịch vòng trái SHIFTS[i] bit mỗi nửa -> Ki = Compress(KLi KRi)
99    VD: generate_keys("10011010") = ("101110", "110011", "001001")
100        KL0 = 1001, KR0 = 1010
101        vòng 1: dịch 1 -> 0011 0101 -> K1 = 101110
102        vòng 2: dịch 2 -> 1100 0101 -> K2 = 110011
103        vòng 3: dịch 1 -> 1001 1010 -> K3 = 001001
104    """
105    if not is_bits(key_8bit, 8):                                # khóa sai định dạng -> báo lỗi
106        raise ValueError("Khóa TinyDES phải là chuỗi 8 bit (0/1).")
107
108    _log(log, "Khóa 8 bit", key_8bit)
109    kl, kr = key_8bit[:4], key_8bit[4:]                         # VD KL0 = 1001, KR0 = 1010
110    _log(log, "KL0 | KR0", f"{kl} {kr}", "Chia đôi khóa")
111    keys = []
112    for i, s in enumerate(SHIFTS, start=1):                     # i = 1, 2, 3 ; s = 1, 2, 1
113        kl, kr = left_shift(kl, s), left_shift(kr, s)           # dịch TIẾP từ kết quả vòng trước
114        _log(log, f"KL{i} | KR{i}", f"{kl} {kr}", f"Dịch vòng trái {s} bit mỗi nửa")
115        k = permute(kl + kr, COMPRESS)                          # nén 8 -> 6 bit
116        _log(log, f"K{i}", k, "Compress: k5 k1 k3 k2 k7 k0")
117        keys.append(k)
118    return tuple(keys)                                          # (K1, K2, K3)

Các hộp thay đổi thế nào khi chạy

Lúckl | krk (chìa vừa làm)keys (giỏ chìa)
Sau dòng cắt đôi1001 | 1010[]
Vòng 1 (i = 1, s = 1)0011 | 0101 101110['101110']
Vòng 2 (i = 2, s = 2)1100 | 0101 110011['101110', '110011']
Vòng 3 (i = 3, s = 1)1001 | 1010 001001['101110', '110011', '001001']

Dòng for i, s in enumerate(SHIFTS, start=1): đi qua từng số trong SHIFTS, bỏ số thứ tự vào hộp i (đếm từ 1), bỏ số đó vào hộp s. Dòng kl, kr = left_shift(kl, s), left_shift(kr, s) ghi đè lên hộp cũ, nên vòng sau xoay tiếp từ kết quả vòng trước.

A4

Tra bảng S-box: 6 ô thành 4 ô

slide 69–70 · hàm sbox_lookup

Slide nói

Hai bít b0b5 xác định hàng, bốn bít b1b2b3b4 xác định cột. Dựa vào bảng tính được 4 bít đầu ra.

Hiểu nôm na

Giống tra bảng cửu chương. Vào 100101: ô đầu + ô cuối = 11 = hàng 3; 4 ô giữa 0010 = cột 2; ô đó ghi 8 → 1000.

core/tinydes_core.pydòng 124–133
124def sbox_lookup(bits6):
125    """
126    Tra S-box: hàng = b0 b5 (bit đầu + bit cuối), cột = b1 b2 b3 b4 (4 bit giữa) -> 4 bit.
127    Trả về (4 bit kết quả, hàng, cột).
128    VD: sbox_lookup("101010"): hàng = "10" = 2, cột = "0101" = 5 -> SBOX[2][5] = 6 -> ("0110", 2, 5)
129    """
130    row = int(bits6[0] + bits6[5], 2)       # ghép b0 và b5 rồi đổi từ nhị phân sang số  VD "10" -> 2
131    col = int(bits6[1:5], 2)                # 4 bit giữa b1 b2 b3 b4                     VD "0101" -> 5
132    # format(..., "04b"): đổi số sang nhị phân đủ 4 chữ số  VD 6 -> "0110"
133    return format(SBOX[row][col], "04b"), row, col

Máy xay F: Expand → XOR chìa → S-box → P-box

slide 68–70 · hàm f_function

Slide nói

F(R, K) = P-box( S-box( Expand(R) ⊕ K ) ).

Hiểu nôm na

4 việc nối đuôi nhau, mỗi việc bỏ kết quả vào 1 hộp mới: half4 → ex → x → s → f.

core/tinydes_core.pydòng 136–150
136def f_function(half4, subkey, log=None, tag=""):
137    """
138    F(R, K) = P-box( S-box( Expand(R) ⊕ K ) ), trả về 4 bit.
139    VD vòng 1 của ví dụ: R0 = "1100", K1 = "101110"
140        Expand = 001011,  ⊕K1 = 100101,  S-box = 1000,  P-box = 0100
141    """
142    ex = permute(half4, EXPAND)             # 4 -> 6 bit                  VD 1100 -> 001011
143    _log(log, f"{tag} Expand", ex, "b2 b3 b1 b2 b1 b0")
144    x = xor(ex, subkey)                     # XOR với khóa con 6 bit       VD 001011 ⊕ 101110 = 100101
145    _log(log, f"{tag} ⊕ K", x, f"XOR với khóa con {subkey}")
146    s, row, col = sbox_lookup(x)            # 6 -> 4 bit                  VD 100101 -> hàng 3, cột 2 -> 1000
147    _log(log, f"{tag} S-box", s, f"hàng {row}, cột {col}")
148    f = permute(s, PBOX)                    # hoán vị 4 bit               VD 1000 -> 0100
149    _log(log, f"{tag} P-box = F", f, "b2 b0 b3 b1")
150    return f

A6

3 vòng trộn (vòng Feistel)

slide 68 · hàm _encrypt_block

Slide nói

Lᵢ = Rᵢ₋₁ ; Rᵢ = Lᵢ₋₁ ⊕ F(Rᵢ₋₁, Kᵢ). Bản mã C = L3R3.

Hiểu nôm na

Hai bạn chuyền bóng: nửa phải vào máy xay, kết quả trộn vào nửa trái thành nửa phải mới; nửa phải cũ sang làm nửa trái. Cả câu đó là 1 dòng code: left, right = right, xor(left, f).

core/tinydes_core.pydòng 156–167
156def _encrypt_block(bits8, keys, log=None):
157    """
158    Mã hóa 1 khối: 3 vòng  L_i = R_(i-1),  R_i = L_(i-1) ⊕ F(R_(i-1), K_i).  Bản mã = L3 R3.
159    VD: _encrypt_block("01011100", ("101110", "110011", "001001")) = "10010010"
160        L0 R0 = 0101 1100 -> 1100 0001 -> 0001 1001 -> 1001 0010
161    """
162    left, right = bits8[:4], bits8[4:]
163    for i, k in enumerate(keys, start=1):
164        f = f_function(right, k, log, f"Vòng {i}")
165        left, right = right, xor(left, f)   # Python tính hết vế phải trước rồi mới gán cùng lúc
166        _log(log, f"Vòng {i} kết quả", f"{left} {right}", f"L{i} = R{i - 1},  R{i} = L{i - 1} ⊕ F")
167    return left + right

Các hộp left, right qua từng vòng

Lúckfleftright
Sau dòng cắt đôi01011100
Vòng 1101110010011000001
Vòng 2110011010100011001

Cửa ngõ encrypt() và mã cả câu chữ

hàm encrypt, encrypt_bytes

Hiểu nôm na

encrypt(P, K) = kiểm tra đúng 8 bit → làm 3 chìa → 3 vòng → trả (bản mã, nhật ký). Câu chữ thì đổi từng chữ ra 1 byte (8 ô), mã từng byte bằng đúng 3 vòng trên: "Hello" → 67 B3 20 20 A2.

core/tinydes_core.pydòng 184–196
184def encrypt(plain_8bit, key_8bit):
185    """
186    Mã hóa 1 khối 8-bit. Trả về (bản mã, log_trung_gian).
187    VD: encrypt("01011100", "10011010") -> ("10010010", [ ...các bước... ])
188    """
189    if not is_bits(plain_8bit, 8):
190        raise ValueError("Bản rõ TinyDES phải là chuỗi 8 bit (0/1).")
191    log_trung_gian = []                                     # danh sách lưu mọi thanh ghi trung gian

193    _log(log_trung_gian, "Bản rõ", f"{plain_8bit[:4]} {plain_8bit[4:]}", "L0 R0")

core/tinydes_core.pydòng 217–230
217def encrypt_bytes(data, key_8bit, keys=None):
218    """
219    Mã hóa từng byte của data (mỗi byte = 1 khối 8 bit).
220    keys: có thể truyền sẵn (K1, K2, K3) để khỏi sinh lại (brute-force dùng cách này).
221    VD: encrypt_bytes(b"Hello", "10011010") = bytes 67 B3 20 20 A2
222        'H' = 0x48 = 72 -> "01001000" -> mã hóa -> "01100111" -> 103 = 0x67
223    """
224    keys = keys or generate_keys(key_8bit)      # "keys or ...": nếu keys là None thì mới sinh khóa
225    # với mỗi byte b (số 0..255):
226    #   format(b, "08b")  : số -> chuỗi 8 bit       VD 72 -> "01001000"
227    #   _encrypt_block    : mã hóa khối 8 bit       -> "01100111"
228    #   int(..., 2)       : chuỗi nhị phân -> số    -> 103
229    # bytes(...)          : gom các số lại thành dãy byte
230    return bytes(int(_encrypt_block(format(b, "08b"), keys), 2) for b in data)

Đọc dòng bytes(int(_encrypt_block(format(b, "08b"), keys), 2) for b in data) từ trong ra ngoài: số → 8 ô (format) → 3 vòng → số (int(…, 2)) → gom thành dãy byte.

A9

Kẻ xấu chỉ có bản mã: thử 256 khóa, chấm điểm

hàm brute_force_ciphertext_only

Hiểu nôm na

Với mỗi khóa trong 256 khóa: làm 3 chìa, giải mã thử, chấm điểm “giống chữ” (readability_score). Xếp từ cao xuống thấp, lấy vài khóa đầu. Khóa đúng ra câu có nghĩa nên đứng đầu.

core/tinydes_core.pydòng 298–311
298def brute_force_ciphertext_only(cipher_bytes, top=5):
299    """
300    Thử 256 khóa, giải mã bản mã và xếp hạng theo readability_score.
301    Trả về list `top` ứng viên tốt nhất: [{"key", "dec", "subkeys", "score", "plain"}, ...] (hạng 1 trước).
302    VD: brute_force_ciphertext_only(encrypt_bytes("Hẹn gặp lúc 8h".encode(), "11011010"))[0]["key"] = "11011010"
303    """
304    candidates = []
305    for key in all_keys():
306        keys = generate_keys(key)
307        plain = decrypt_bytes(cipher_bytes, key, keys)
308        candidates.append({"key": key, "dec": int(key, 2), "subkeys": keys,
309                           "score": readability_score(plain), "plain": plain})
310    candidates.sort(key=lambda c: c["score"], reverse=True)    # điểm cao nhất lên đầu
311    return candidates[:top]

66    """
67    Chấp nhận 8 ký tự ASCII hoặc 16 ký tự hex.

43def rotl(value, n, bits):
44    """
45    Dịch VÒNG trái n bit trên số dài `bits` bit (bit bị đẩy ra bên trái quay về bên phải).
46    VD: rotl(0b1000, 1, 4) = 0b0001
47        rotl(0xF0CCAAF, 1, 28) = 0xE19955F   (C0 -> C1 khi sinh khóa)
48    """
49    mask = (1 << bits) - 1                      # mặt nạ gồm `bits` số 1, VD bits=4 -> 0b1111
50    # value << n          : dịch trái n bit (n bit đầu tràn ra ngoài phạm vi)      VD 1000 << 1 = 10000
51    # value >> (bits - n) : lấy đúng n bit đầu đó, đưa về cuối                      VD 1000 >> 3 = 0001
52    # "|" ghép 2 phần, "& mask" cắt phần tràn bên trái, chỉ giữ đúng `bits` bit     VD 10001 & 1111 = 0001
53    return ((value << n) | (value >> (bits - n))) & mask

Thiếu n byte thì độn n byte, mỗi byte ghi số n. “Xin chào” = 9 byte 58 69 6E 20 63 68 C3 A0 6F → thiếu 7 → 58 69 6E 20 63 68 C3 A0 6F 07 07 07 07 07 07 07. Lúc mở: đọc byte cuối là 7, bỏ 7 byte.

16def pkcs7_pad(data, block_size=BLOCK_SIZE):
17    """
18    Đệm PKCS#7: thêm n byte, MỖI byte có giá trị n, sao cho tổng độ dài là bội của 8.
19    Luôn thêm từ 1 đến 8 byte (dữ liệu tròn 8 byte vẫn thêm nguyên 1 khối 08 08 ... 08).
20    VD: "Xin chào" = 9 byte  58 69 6E 20 63 68 C3 A0 6F
21        9 % 8 = 1 -> n = 8 - 1 = 7 -> thêm 07 07 07 07 07 07 07 -> 16 byte
22        b"" (rỗng) -> n = 8 -> thêm 8 byte 08
23    """
24    n = block_size - len(data) % block_size  # luôn thêm 1..8 byte
25    #                                          "%" là phép chia lấy dư: 9 % 8 = 1, 16 % 8 = 0 (-> n = 8)
26    return data + bytes([n]) * n             # bytes([7]) = b'\x07'; "* 7" lặp lại 7 lần; "+" nối vào cuối

29def pkcs7_unpad(data, block_size=BLOCK_SIZE):
30    """
31    Bỏ phần đệm: đọc byte cuối = n, kiểm tra n byte cuối đều bằng n, rồi cắt bỏ.
32    VD: ... 6F 07 07 07 07 07 07 07 -> byte cuối = 7 -> bỏ 7 byte -> "Xin chào"
33    Nếu giải mã SAI KHÓA, dữ liệu là rác -> byte cuối thường không hợp lệ -> báo lỗi.
34    """
35    if not data or len(data) % block_size:          # rỗng hoặc không chia hết cho 8 -> không phải bản mã DES
36        raise ValueError("Dữ liệu không phải bội số của 8 byte.")
37    n = data[-1]                                    # data[-1]: phần tử CUỐI (với bytes là 1 số 0..255)
38    # n phải từ 1..8, và n byte cuối (data[-n:]) phải đúng bằng n byte giá trị n
39    if n < 1 or n > block_size or data[-n:] != bytes([n]) * n:
40        raise ValueError("Padding sai - có thể do sai khóa hoặc file không phải bản mã DES.")
41    return data[:-n]                                # data[:-n]: lấy tất cả TRỪ n byte cuối

140def crypt_block_verbose(block, subkeys):
141    """
142    Mã hóa/giải mã 1 khối (8 bytes) kèm log từng vòng. Trả về (bytes, log).
143    - Mã hóa: truyền subkeys = [K1..K16]
144    - Giải mã: truyền subkeys = [K16..K1] (tức subkeys[::-1])
145
146    VD: block = 0123456789ABCDEF, khóa 133457799BBCDFF1
147        IP     -> L0 = CC00CCFF, R0 = F0AAF0AA
148        Vòng 1 -> L1 = F0AAF0AA, R1 = EF4A6544
149        ...
150        Vòng 16-> L16 = 43423234, R16 = 0A4CD995
151        IP⁻¹(R16‖L16) -> 85E813540F0AB405
152    """
153    log = []
154    b = int.from_bytes(block, "big")                # 8 byte -> số 64 bit
155    ip = permute(b, IP, 64)                         # hoán vị khởi tạo IP
156    left, right = ip >> 32, ip & 0xFFFFFFFF         # chia đôi: 32 bit trái, 32 bit phải
157    log.append({"vong": "IP", "l": f"{left:08X}", "r": f"{right:08X}"})
158    for i, k in enumerate(subkeys, start=1):        # 16 vòng, i = 1..16, k = khóa con của vòng
159        detail = {}
160        left, right = right, left ^ feistel_f(right, k, detail)
161        # Python tính HẾT vế phải trước rồi mới gán, nên:
162        #   left mới  = right cũ                         (L_i = R_{i-1})
163        #   right mới = left cũ XOR F(right cũ, K_i)     (R_i = L_{i-1} ⊕ F(R_{i-1}, K_i))
164        log.append({"vong": f"Vòng {i}", "k": f"{k:012X}", "l": f"{left:08X}", "r": f"{right:08X}", **detail})
165        #                                             **detail: trải các khóa e, xor, s, f của dict detail vào dict này
166    out = permute((right << 32) | left, IP_INV, 64)  # đảo L/R sau vòng 16
167    # DES quy định sau vòng 16 KHÔNG tráo nữa. Vòng lặp trên đã lỡ tráo 1 lần,
168    # nên ghép ngược lại thành R16‖L16 (right đứng trước) để hủy lần tráo thừa, rồi IP⁻¹.
169    log.append({"vong": "IP⁻¹", "out": f"{out:016X}"})

120def feistel_f(r32, k48, detail=None):
121    """
122    Hàm F của 1 vòng: F(R, K) = P( S( E(R) XOR K ) )
123    detail: dict tùy chọn để lưu giá trị trung gian (phục vụ in log).
124
125    VD vòng 1: R0 = F0AAF0AA, K1 = 1B02EFFC7072
126        E  -> 7A15557A1555
127        ⊕K -> 6117BA866527
128        S  -> 5C82B597
129        P  -> f = 234AA9BB
130    """
131    e = permute(r32, E, 32)     # mở rộng R từ 32 -> 48 bit (một số bit được lặp lại)

97def sbox_sub(x48):
98    """
99    Cho 48 bit qua 8 S-box: mỗi nhóm 6 bit -> 4 bit, tổng cộng ra 32 bit.
100    Với nhóm 6 bit b1 b2 b3 b4 b5 b6: hàng = b1b6 (0..3), cột = b2b3b4b5 (0..15).
101
102    VD: x48 = 6117BA866527
103        S1: 011000 -> hàng 00=0, cột 1100=12 -> S1[0][12] = 5
104        S2: 010001 -> hàng 01=1, cột 1000=8  -> S2[1][8]  = C
105        ... -> kết quả 5C82B597
106    """
107    out = 0
108    for i in range(8):                              # i = 0..7 tương ứng S1..S8
109        chunk = (x48 >> (42 - 6 * i)) & 0x3F        # lấy nhóm 6 bit thứ i (0x3F = 0b111111)
110        #                                             nhóm 0 nằm ở bit trên cùng nên dịch 42, nhóm 1 dịch 36, ..., nhóm 7 dịch 0
111        row = ((chunk >> 4) & 0b10) | (chunk & 1)   # hàng = bit đầu (b1) và bit cuối (b6)
112        #                                             chunk >> 4 còn "b1 b2", & 0b10 giữ b1 ở vị trí số 2; chunk & 1 = b6
113        #                                             VD chunk=011000: b1=0, b6=0 -> row = 0
114        col = (chunk >> 1) & 0xF                    # cột = 4 bit giữa b2..b5 (bỏ b6, giữ 4 bit)
115        #                                             VD 011000 >> 1 = 01100, & 1111 = 1100 = 12
116        out = (out << 4) | S_BOX[i][row][col]       # tra S-box thứ i, ghép 4 bit kết quả vào cuối
117    return out

Cùng việc với permute của TinyDES. Vì là số nên “lấy ô số pos” viết thành (value >> (in_bits - pos)) & 1: dịch cho ô đó về cuối rồi giữ đúng 1 bit. Bảng của DES đếm từ 1 (slide đếm từ 0).

23def permute(value, table, in_bits):
24    """
25    Hoán vị bit: bit thứ i của kết quả = bit ở vị trí table[i] của value (đánh số từ 1).
26    value   : số nguyên đầu vào, dài in_bits bit
27    table   : danh sách vị trí cần lấy, VD IP, E, P, PC1, PC2
28    in_bits : độ dài đầu vào (64, 56 hoặc 32)
29    Kết quả dài len(table) bit -> cùng 1 hàm vừa hoán vị, vừa rút gọn (PC1, PC2), vừa mở rộng (E).
30
31    VD: permute(0b1011, [2, 4, 3, 1], 4)
32        đầu vào b1=1 b2=0 b3=1 b4=1 -> lấy b2,b4,b3,b1 = 0,1,1,1 -> 0b0111
33    """
34    out = 0                                     # kết quả bắt đầu bằng 0, sẽ ghép dần từng bit vào cuối
35    for pos in table:                           # duyệt từng vị trí trong bảng, VD pos = 2, rồi 4, rồi 3, rồi 1
36        bit = (value >> (in_bits - pos)) & 1    # dịch phải để bit thứ pos về cuối, "& 1" giữ đúng bit đó
37        #                                         VD value=1011, in_bits=4, pos=2: 1011 >> 2 = 10, & 1 = 0
38        out = (out << 1) | bit                  # dịch out sang trái 1 chỗ rồi gắn bit mới vào cuối
39        #                                         VD out=0 -> 0, rồi 01, rồi 011, rồi 0111
40    return out

318        t0 = time.perf_counter()                            # bấm giờ
319        for i, blk in enumerate(blocks):
320            out, log = fn(blk, key)                         # mã hóa/giải mã 1 khối, kèm log
321            out_blocks.append(out)
322            if i < MAX_LOG_BLOCKS:
323                # log[len(key_log):] bỏ phần sinh khóa ở đầu log (đã hiển thị riêng)
324                block_logs.append({"input": blk, "output": out, "steps": log[len(key_log):]})
325
326        elapsed = (time.perf_counter() - t0) * 1000         # giây -> mili-giây
327        out_bytes = bytes(int(b, 2) for b in out_blocks)    # ["10010010", ...] -> b'\x92...'
328        traces = [tinydes_core.trace(b, key, decrypt=(action == "dec")) for b in blocks[:MAX_LOG_BLOCKS]]
329        result = {
330            "subkeys": keys, "key_log": key_log, "blocks": block_logs,
331            "total_blocks": len(blocks),
332            "out_bin": " ".join(out_blocks),                # VD "10010010 01100111"
333            "out_hex": out_bytes.hex(" ").upper(),          # VD "92 67"
334            # giải mã thì thử đổi bytes -> chữ; errors="replace": byte không hợp lệ thành dấu �
335            "out_text": out_bytes.decode("utf-8", errors="replace") if action == "dec" else None,
336            "action": action, "fmt": fmt,
337            # Dữ liệu minh họa từng bit (sinh khóa, 3 vòng Feistel) cho vài khối đầu
338            "traces": traces,
339        }
340        # Dải luồng của khối đầu: Đầu vào -> Vòng 1 -> Vòng 2 -> Vòng 3 (mã hóa) hoặc 3 -> 2 -> 1 (giải mã)
341        first = traces[0]
342        result["flow"] = [("Đầu vào", first["input"])] + [(f"Vòng {r['n']}", r["output"]) for r in first["rounds"]]
343        if action == "enc":  # tự giải mã ngược để chứng minh D(E(P)) = P
344            original = bytes(int(b, 2) for b in blocks)
345            back = tinydes_core.decrypt_bytes(out_bytes, key)
346            result["roundtrip"] = {
347                "ok": back == original,
348                "bin": " ".join(format(b, "08b") for b in back),
349                "text": back.decode("utf-8", errors="replace") if fmt == "text" else None,
350            }
351        db.add_history("TinyDES", action_name(action), raw_input,       # ghi lịch sử (KHÔNG ghi khóa)
352                       result["out_text"] if action == "dec" and fmt == "text" else result["out_hex"],
353                       len(out_bytes), round(elapsed, 3), note=f"{len(blocks)} khối 8-bit")
354        return render("sdes.html", sdes=result)             # trả trang sdes.html kèm kết quả
355    except ValueError as e:                                 # nhập sai -> hiện thông báo lỗi trên trang
356        db.add_history("TinyDES", action_name(action), raw_input, status="error", note=str(e))
357        return render("sdes.html", sdes_error=str(e))

Phòng chat: An gửi tin

hàm chat_send · gọi từ static/chat.js

Hiểu nôm na

Trang chat không tải lại trang. JavaScript gửi JSON {"algo", "key", "text"} lên /api/chat/send. Hàm lấy 2 cái máy (mã hóa, giải mã) từ chat_cipher, mã hóa tin của An, giải mã luôn bằng cùng khóa để ra tin Bình nhận, rồi trả JSON về. weak báo khóa yếu khi 3 chìa không khác nhau hết.

733    An gửi 1 tin. Trả về bản mã (thứ đi trên đường truyền) và tin Bình giải mã được.
734    VD vào {"algo": "tinydes", "key": "11011010", "text": "Hello"}

744        cipher = enc(text.encode("utf-8"))                  # phía AN: chữ -> byte -> mã hóa
745        bob = dec(cipher).decode("utf-8", errors="replace")  # phía BÌNH: giải mã bằng cùng khóa -> chữ
746        elapsed = (time.perf_counter() - t0) * 1000
747        # Khóa TinyDES yếu: 3 khóa con không khác nhau hết (VD 11110000 -> 3 khóa con giống hệt)
748        weak = algo == "tinydes" and len(set(tinydes_core.generate_keys(key))) < 3

750                       note="TinyDES" if algo == "tinydes" else "DES")
751        return jsonify(ok=True, cipher_hex=cipher.hex(" ").upper(), n_bytes=len(cipher), n_plain=len(text.encode("utf-8")),
752                       bob_text=bob, elapsed=round(elapsed, 2), weak=weak)
753    except ValueError as e:
754        return jsonify(ok=False, error=str(e)), 400

Phòng chat: kẻ xấu vét cạn và sửa tin

hàm chat_attack, chat_tamper

Hiểu nôm na

chat_attack: chỉ dùng bản mã. TinyDES thì gọi lại A9 (thử 256 khóa). DES thì thử 2.000 khóa để đo tốc độ, rồi tính thử hết 256 khóa mất bao nhiêu năm.
chat_tamper: đổi 1 bit (cipher[index] ^= 0x01) rồi cho Bình giải mã bản đã sửa. DES hỏng khối cuối thì pkcs7_unpad báo lỗi đệm.

757@app.post("/api/chat/attack")
758def chat_attack():
759    """
760    Kẻ xấu vét cạn khóa. Chỉ dùng BẢN MÃ, không dùng khóa thật để tìm.
761    (khóa thật chỉ được gửi lên để kiểm chứng "kẻ xấu đoán đúng chưa" vì đây là mô phỏng)
762    TinyDES: thử đủ 256 khóa -> thường đoán ra ngay.
763    DES    : thử DES_TRY khóa để đo tốc độ, rồi tính cần bao lâu để thử hết 2^56 khóa.
764    """
765    data, algo, key = chat_json()
766    try:
767        cipher = bytes.fromhex(str(data.get("cipher_hex", "")))   # "43 61 DA" -> b'\x43\x61\xda'
768        if not cipher:
769            raise ValueError("Không có bản mã để tấn công.")
770        t0 = time.perf_counter()
771        if algo == "tinydes":
772            top = tinydes_core.brute_force_ciphertext_only(cipher, top=3)
773            elapsed = (time.perf_counter() - t0) * 1000
774            guess = top[0]                                  # ứng viên điểm "giống chữ" cao nhất
775            success = guess["key"] == key
776            db.add_history("Brute-force", "Kẻ xấu vét cạn (chat)", data.get("cipher_hex"), guess["key"], len(cipher),
777                           round(elapsed, 3), status="ok" if success else "error", note="TinyDES, 256 khóa")
778            return jsonify(ok=True, algo=algo, tried=tinydes_core.KEY_SPACE, elapsed=round(elapsed, 2), success=success,
779                           top=[{"key": c["key"], "score": c["score"],
780                                 "text": c["plain"].decode("utf-8", errors="replace")} for c in top])
781        # DES: chỉ giải mã thử khối đầu tiên với khóa 0, 1, 2, ... (mỗi lần phải sinh lại 16 khóa con)
782        first = cipher[:8]
783        for k in range(DES_TRY):
784            des_core.decrypt_block(first, k.to_bytes(8, "big"))   # số k -> 8 byte làm khóa thử
785        elapsed = (time.perf_counter() - t0) * 1000
786        per_sec = DES_TRY / (elapsed / 1000)                # tốc độ: số khóa thử được mỗi giây
787        years = 2 ** 56 / per_sec / (3600 * 24 * 365)       # thời gian thử hết 2^56 khóa, đổi ra năm
788        db.add_history("Brute-force", "Kẻ xấu vét cạn (chat)", data.get("cipher_hex"), "không tìm thấy", len(cipher),
789                       round(elapsed, 3), status="error", note=f"DES, thử {DES_TRY} khóa")
790        return jsonify(ok=True, algo=algo, tried=DES_TRY, elapsed=round(elapsed, 2), success=False,
791                       per_sec=round(per_sec), years=years, total_keys=2 ** 56)
792    except ValueError as e:
793        return jsonify(ok=False, error=str(e)), 400

825def chat_tamper():
826    """
827    Kẻ xấu đổi 1 bit của byte thứ `index` trong bản mã rồi chuyển tiếp. Bình giải mã bản mã đã bị sửa.

846                       bob_text=bob, bob_error=bob_error)
