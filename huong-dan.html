Chỉ phần web: app.py (Flask) nhận yêu cầu, HTML trong templates/ hiện trang, JavaScript trong static/ lo phòng chat và trình chiếu

Cách chạy

  1. Mở terminal ở thư mục đồ án.
  2. Lần đầu: tạo môi trường ảo python -m venv .venv.
  3. Bật môi trường ảo: source .venv/bin/activate (Windows: .venv\Scripts\activate).
  4. Lần đầu: cài thư viện pip install -r requirements.txt (Flask và pycryptodome; pycryptodome chỉ để so sánh).
  5. Chạy python app.py, chờ dòng Running on http://127.0.0.1:5000.
  6. Mở trình duyệt vào http://127.0.0.1:5000. Tắt máy chủ: Ctrl + C.

Khi chạy python app.py, Python đọc file từ trên xuống, đăng ký các địa chỉ @app.get / @app.post, rồi app.run() bật máy chủ và đứng chờ. Trình duyệt vào địa chỉ nào thì hàm gắn với địa chỉ đó mới chạy.

Một lần bấm nút đi qua những đâu

Ví dụ: ở trang TinyDES từng bước, nhập bản rõ 01011100, khóa 10011010, bấm Mã hóa.

  1. HTML (templates/sdes.html): form có method="post" action="/sdes_demo". Bấm nút thì trình duyệt gửi các ô nhập lên máy chủ:
    sdes_key=10011010 & sdes_fmt=bin & sdes_input=01011100 & sdes_action=enc
  2. Flask (app.py) thấy địa chỉ /sdes_demo → chạy hàm sdes_demo(). Hàm đọc từng ô bằng request.form.get("sdes_key").
  3. sdes_demo() gọi hàm mã hóa trong core/, nhận về bản mã 10010010 và các bước trung gian.
  4. Lịch sử (db.py): db.add_history(...) ghi 1 dòng vào history.db.
  5. Trả trang: render("sdes.html", sdes=kết_quả). Jinja mở lại sdes.html, điền {{ sdes.out_bin }} thành 10010010, gửi trang HTML hoàn chỉnh về trình duyệt.
  6. Trình duyệt tải lại cả trang và hiện kết quả.

Mọi trang có form (TinyDES, DES, Tấn công, Đo thời gian, Kiểm thử) đều chạy theo đúng 6 bước này. Riêng phòng chat không tải lại trang, xem mục Phòng chat.

app.py: máy chủ web (Flask)

Mỗi địa chỉ web gắn với 1 hàm Python bằng một dòng @app.get hoặc @app.post đặt ngay trên hàm:

app = Flask(__name__)                    tạo web; Flask tự tìm templates/ và static/

@app.get("/sdes")                        mở trang (GET): chỉ trả form trống
def sdes_page():
    return render("sdes.html")

@app.post("/sdes_demo")                  form gửi lên (POST)
def sdes_demo():
    key = request.form.get("sdes_key")   đọc ô có name="sdes_key"
    ...                                  gọi core/ để mã hóa
    db.add_history(...)                  ghi lịch sử
    return render("sdes.html", sdes=kết_quả)   trả trang HTML có kết quả

@app.post("/api/chat/send")              API cho JavaScript
def chat_send():
    data = request.get_json()            đọc JSON chat.js gửi lên
    ...
    return jsonify(ok=True, cipher_hex=..., bob_text=...)   trả JSON, không trả HTML
Thứ dùng trong app.pyĐể làm gì
request.form / request.argsĐọc ô nhập của form (POST) / tham số trên URL (GET)
request.filesĐọc tệp người dùng chọn (trang DES)
request.get_json()Đọc JSON do chat.js gửi lên
render(...)Hàm phụ của nhóm, gọi render_template: ghép dữ liệu vào file HTML. Luôn gửi kèm form (để điền lại ô vừa nhập) và bảng S-box
jsonify(...)Trả JSON cho JavaScript (phòng chat)
send_file(...)Gửi tệp đã mã hóa về cho người dùng tải (/download/<token>)
redirect(url_for(...))Chuyển sang trang khác (VD xóa lịch sử xong quay lại /history)
@app.errorhandler(413)Tệp lớn hơn 20 MB thì báo lỗi dễ hiểu thay vì trang lỗi mặc định
try / except ValueErrorNhập sai (khóa không đủ 8 bit...) thì hiện chữ đỏ trên trang, không làm sập web

HTML viết thế nào (Jinja)

Flask dùng Jinja để ghép dữ liệu vào HTML. Mọi trang dùng chung khung templates/base.html (menu trái, tiêu đề, chân trang). Mỗi trang con chỉ viết phần riêng của nó:

{% extends "base.html" %}              dùng khung chung
{% set active = 'sdes_page' %}          tô sáng mục này trên menu
{% block heading %}TinyDES{% endblock %}   điền vào chỗ trống "heading" của base.html
{% block content %}
  <form method="post" action="{{ url_for('sdes_demo') }}">   url_for -> /sdes_demo
    <input name="sdes_key">                      app.py đọc bằng request.form.get("sdes_key")
  </form>
  {% if sdes %}                                  chỉ hiện khi đã có kết quả
    Bản mã: {{ sdes.out_bin }}                   in giá trị Python gửi sang
    {% for k in sdes.keys %} {{ k }} {% endfor %}  lặp như for của Python
  {% endif %}
{% endblock %}

Từng file HTML có gì, form gửi gì, nhận biến gì: xem mục Từng trang HTML ngay dưới.

Muốn thêm 1 trang: viết hàm @app.get("/ten") trong app.py trả về render("ten.html"), tạo templates/ten.html bắt đầu bằng {% extends "base.html" %}, rồi thêm 1 dòng vào biến menu trong base.html.

Phòng chat “An gửi Bình” chạy thế nào

Chat dùng cái gì?

  • Không có máy chủ chat riêng, không dùng WebSocket. An, đường truyền và Bình nằm chung 1 trang web để mô phỏng.
  • Trình duyệt dùng JavaScript fetch() gửi dữ liệu dạng JSON lên Flask (app.py), nhận JSON về, rồi chat.js tự vẽ bong bóng tin. Trang không tải lại.
  • Mã hóa và giải mã vẫn chạy ở Python (core/), giống mọi trang khác.

Một tin nhắn đi qua những đâu

  1. An gõ “Hello”, khóa 11011010, bấm Mã hóa & gửi.
  2. chat.js (hàm send()) gửi lên máy chủ:
    POST /api/chat/send {"algo": "tinydes", "key": "11011010", "text": "Hello"}
  3. app.py (hàm chat_send()): chữ → byte (text.encode("utf-8")) → An mã hóa bằng tinydes_core.encrypt_bytes() → Bình giải mã lại bằng cùng khóa → trả JSON:
    {"ok": true, "cipher_hex": "43 61 DA DA C0", "bob_text": "Hello", "weak": false, ...}
  4. chat.js nhận JSON, vẽ 3 thứ: bong bóng bên An (tin gốc), gói tin ở giữa (cipher_hex, thứ kẻ xấu thấy), bong bóng bên Bình (bob_text).
  5. Các nút trên gói tin gửi tiếp bản mã lên các API của kẻ xấu (bảng dưới).
NútĐịa chỉ (API)Hàm trong app.pyGửi lênNhận về

Vét cạn khóa/api/chat/attackchat_attack()algo, cipher_hexTinyDES: 3 khóa điểm cao nhất; DES: tốc độ, số năm

Vét cạn có gửi kèm khóa thật, nhưng máy chủ không dùng khóa đó để tìm, chỉ để báo “kẻ xấu đoán đúng chưa”. Tấn công chọn bản rõ dùng khóa thật để làm hộp đen: kẻ xấu chỉ gọi được hàm mã hóa, không đọc được khóa.

Muốn chat thật giữa 2 máy thì cần thêm gì

Bản hiện tại chỉ mô phỏng trên 1 trang. Muốn An và Bình ngồi 2 máy khác nhau:

  1. Chạy máy chủ cho máy khác vào được: app.run(host="0.0.0.0"), hai máy chung wifi vào http://<IP máy chủ>:5000/chat.
  2. Lưu tin vào cơ sở dữ liệu (thêm 1 bảng trong history.db), chỉ lưu bản mã.
  3. Bên Bình hỏi máy chủ vài giây 1 lần (setInterval + fetch), hoặc dùng Flask-SocketIO (WebSocket) để máy chủ đẩy tin ngay.
  4. Giải mã ở phía Bình bằng khóa Bình tự nhập, máy chủ không giữ khóa.
